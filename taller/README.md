# Taller: Clonación de voz con Qwen3-TTS

## Instalación (uv only)

```bash
git clone https://github.com/AfkaraLP/qwen3-tts-webui.git
cd qwen3-tts-webui
uv sync
uv run start_server.py
```

Interfaz web en http://localhost:8000
